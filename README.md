# 纸本文物外借展陈 · 紫外灯光联动复核（静态站点）

保管员在浏览器录入 **2–6 个展柜**的：

- 滑动暴露窗口长度 `L` 与**最大窗口剂量限额**；
- **累计剂量上限**；
- 每柜 **3–8 盏灯**，每盏灯一个或多个**左闭右开**启停区间 `[启动, 停止)` 及该区间紫外照度。

系统在**连续时间**上把所有灯的区间叠加为**分段恒定照度**，对任意指定长度的连续滑动窗口
**精确求最大积分剂量**，并按展柜展示完整时段累计剂量、达到最大窗口剂量的**精确起止时刻**与
窗口内照度变化；超限时给出按**展柜输入顺序**、再按**违规窗口起点**稳定确定的**首项证据**。

## 计算方法（不使用固定采样点）

- 全部数值用 **BigInt 精确有理数**保存与运算，不存在浮点误差；
- 所有灯的左闭右开区间端点合并为切分点，段内照度为覆盖该段的灯照度之和（分段恒定）；
- 窗口剂量 `D(s)=∫[s,s+L) i(t)dt`。在相邻「临界起点」之间 `i(s)`、`i(s+L)` 恒定，
  `D` 为线性函数，其最大值必在端点取得。临界起点恰为 `{切分点} ∪ {切分点 − L}`，
  只需在这有限的、精确的候选起点上求值，连续时间意义下精确；
- 最早违规临界时刻在每段上解一次一次方程得到，同样是精确时刻；
- 同值取最早起点，证据稳定可复现。

时间单位 h，照度 μW/cm²，剂量 μW·h/cm²。

## 校验规则（非法时一次列出全部问题并阻止复核）

- 展柜 2–6 个、每柜灯 3–8 盏；
- 窗口长度、窗口限额、累计上限须为非负数值且大于 0；窗口限额不得大于累计上限；
- 灯号在同一展柜内不得重复、不得为空；
- 每个区间停止必须严格晚于启动；同一盏灯的区间不得相互重叠
  （端点相接合法：`[a,b) ∪ [b,c)`）；照度须为非负数值。

## 数据保存

草稿与**最近一次有效复核结果**保存在本机浏览器 `localStorage`，关闭重开可继续调整。
复核结果带草稿指纹：**草稿一旦修改，旧结论立即失效且不再显示**，需重新发起复核。

## 本地开发

```bash
npm install --cache .npm-cache   # 如全局 npm 缓存目录不可写
npm test                         # 逻辑 + DOM 测试（node --test）
npm run dev                      # 开发服务器
npm run build                    # 生产构建到 dist/
npm run verify                   # 逻辑校验 + 生产构建 + 页面可访问检查
```

## Docker

```bash
# 宿主机端口可配置（默认 8080）
HOST_PORT=8080 docker compose up -d --build web
# 健康检查：GET /healthz

# 一次性校验服务：完成逻辑校验、生产构建、页面可访问检查后自行退出，
# 退出码报告结果（0 通过，非 0 失败）
docker compose up --build verify
docker compose inspect verify 2>/dev/null; echo $?   # 或 docker compose ps -a
```

`Dockerfile` 为多阶段构建：

- `web` 目标：nginx 托管 `vite build` 的静态产物，含容器健康检查；
- `verify` 目标：Node 镜像内运行 `scripts/verify.sh`
  （`npm test` → `vite build` → 对健康的 `web` 服务做 HTTP 可访问检查）。
